Tips for parents

  • One letter sheet a day is plenty. Start with the "Learn the Letter" sheets.
  • Let your child trace the big letter with a finger first, then use a pencil.
  • Say the letter sound together, like "o" as in octopus.
  • Print the PDF on A4 at actual size for the best result.
