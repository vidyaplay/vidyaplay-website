Green Colour Worksheets for Nursery

Colour of the week: green! Spot the green things, colour a big tree with green leaves, and help the frog find the green leaf in an easy maze.

Free · A4 PDF · Please print in colour · Ages 2.5 to 4

All 3 green worksheets in one file

One page a day for a green week.

Download the pack (PDF)
  • Worksheet 1

    Green Things

    Circle the pictures that are green.

    Download PDF
  • Worksheet 2

    Colour the Tree

    Colour the leaves green and the trunk brown.

    Download PDF
  • Worksheet 3

    Help the Frog Find Green

    Draw a green line through the maze to the leaf.

    Download PDF

Tips for parents

  • Name each picture out loud, then ask: Is it green?
  • Go on a green walk: find leaves, grass and plants.
  • In the maze, let your child try first; point to the walls if they get stuck.
